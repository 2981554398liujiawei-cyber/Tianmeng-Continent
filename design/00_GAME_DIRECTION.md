# 00 — 游戏方向总纲（BG3 风格设计原则）

> 依据任务卡 TM-P2-007 第 23 节编制。本文件是《天梦大陆》所有系统与内容设计的最高层方向。
> 所有后续设计文档、开发任务卡与实现决策必须与此方向一致；与系统边界冲突时以 `02_SYSTEM_BOUNDARIES.md` 的硬边界为准。
>
> 标签规范：`[CANON]`=已上线实现；`[PROJECT-AU]`=项目对原著的改编；`[PLANNED]`=未来规划；`[UNKNOWN]`=无法核实。

## 1. 项目定位

- 单机浏览器文字 D20 奇幻 CRPG《天梦大陆》，单人游玩，玩家控制一名主角与最多 2 名伙伴 `[CANON]`。
- 战斗为项目自己的轻量回合制：我方最多 3 人、敌方最多 3 人 `[CANON]`（P2-007 硬约束）。
- 实现风格：纯函数 + 数据 registry + 少量 UI 组件，禁止 ECS / 巨型 CombatEngine 层级 / AI planner / Skill DSL 等过度设计（任务卡 §57）。
- 明确不做：普通宠物系统、MMO 化、网格/站位战斗、动态等级缩放、实时地图移动速度 `[PROJECT-AU]`（AU-002/004/005）。

## 2. BG3 七原则

> 以下 7 条原则为任务卡 §23 原文整理，是内容与系统设计的指导方针。每条附"落地"说明指向本项目既有状态或 P2-007 固化点。

### 原则 1：正式剧情战优先 authored encounter，不做动态等级缩放

正式剧情战由数据设计固定阵容，敌人不会因玩家等级或队伍规模自动变化。

- 落地：Encounter V2 采用 `EncounterDefinition`（fixed / weighted），`sum(count) <= 3`；禁止"玩家 2 级→敌人 2 级"式动态缩放 `[P2-007]`。
- 队伍变强后，玩家应真实感受到自己更强。

### 原则 2：任务优先考虑多解

任务设计提供多条合理解法：战斗 / 属性检定 / 职业专长 / Luck / 伙伴知识 / 环境利用 / 道具。

- 落地：重要任务最好提供 3 条路径，至少 2 条 `[P2-007]`。任务关键物禁止被低概率掉落卡死（guaranteed 或任务结算单独给，任务卡 §5.3）。

### 原则 3：重要决定由在场或合理知情伙伴产生 approves / disapproves

伙伴只对自身在场或合理知情的重大决定表态，不凭空点评。

- 落地：Relationship/Approval 规则固化在 `relationships/approval_rules.md`；重复刷同一句对话不重复收益（任务卡 §36）。

### 原则 4：伙伴必须对自己的知识领域插话

每个伙伴拥有自己的知识领域，遇到相关话题时主动发言，体现角色差异。

- 落地：角色档案字段 10「主线插话方向」固化各伙伴的知识领域与插话风格 `[P2-007 Design Bible]`。

### 原则 5：Long Rest / 营地承担伙伴剧情、恋爱、冲突和成长

营地是伙伴关系发展的主场，而不是纯数值恢复界面。

- 落地：`[CANON]` 现有 Long Rest 恢复机制保留；伙伴剧情/恋爱/冲突/成长事件设计均围绕营地场景展开（任务卡 §23 原则 5）。

### 原则 6：战斗与探索应有可感知奖励

每一次有效战斗与探索都给玩家明确回报：经验、战利品、金币、世界变化。

- 落地：Loot V2 每名敌人有掉落表（guaranteed / random / lucky）；VictorySummary 统一展示 XP、金币、战利品并自动收入背包（任务卡 §6）。

### 原则 7：队伍组成要影响对白、解法和战斗，不只是数值

带不同的伙伴，对话、解法、战斗体验应实质不同。

- 落地：伙伴拥有独立支线、价值观与战斗定位；P2-007 全员战斗由玩家控制所有 friendly（任务卡 §10），队伍组成决定可用技能与解谜路径。

## 3. 内容裁定速查

| 裁定 | 结论 | 出处 |
|---|---|---|
| 普通宠物系统 | 明确不做；特殊女性伙伴统一走 Companion / Relationship / Party | 任务卡 §2.1 / AU-002 |
| 战斗规模 | 3v3 硬上限 | 任务卡 §2.2 / AU-004 |
| Combat V3 数学 | 命中/护甲/暴击公式冻结，只泛化为多人队列 | 任务卡 §2.3 |
| 动态等级缩放 | 禁止；遭遇由数据设计 | 任务卡 §2.4 |
| 坐骑 | 非战斗单位，只提供属性加成与探索能力 | 任务卡 §18 / AU-003 |
| Golden Rabbit | 硬冻结，禁止任何系统连接 | 任务卡 §39 |

# Combat UI V7 Spec

状态：PLANNED 草案；生产界面仍按 3v3 验收。

顶部显示战斗、回合、当前行动者；中部左右单位卡；下方战报/详细日志；底部固定 Action Bar。卡片仅显示名称、Lv、HP、可选 MP、攻击、护甲、敏捷，不显示 instanceId 或常驻 raw grid。

4v4 预留为换行/滚动卡片，不改变行动顺序。死亡卡灰显保留占位；当前行动高亮。攻击/敌方技能选存活敌人，治疗/护盾选存活友方，自身技能直执行；picker 有取消且不耗行动。

需测试键盘、窄屏、对比度、日志滚动和读档恢复。不得引入网格、拖拽排阵、AP 或 Bonus Action。Save V6 冻结，P2-011 未推进；Golden Rabbit freeze 不增加战斗线索入口。

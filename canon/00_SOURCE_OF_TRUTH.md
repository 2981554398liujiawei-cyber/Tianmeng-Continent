# 00 — Source of Truth 权威优先级

> 本文件是《天梦大陆》项目 Canon 层的总纲。任何资料引用、剧情裁定、人物档案都必须先回到本文件的优先级判断来源。
> 本文件由任务卡 TM-P2-007 第 7 节原文编制，本阶段由项目正式裁定（见 `00_DECISIONS.md`）背书。

## 1. 权威优先级（任务卡第 7 节原文）

```
最高优先级：

1. 用户当前明确裁定
2. 项目 canon 当前正式裁定
3. 原著明确事实
4. 已上线且未被正式废止的游戏连续性
5. 旧设计文档
6. 临时推演
```

任何冲突：
**高优先级覆盖低优先级。**

## 2. 冲突覆盖规则

- 高优先级条目与低优先级条目冲突时，以高优先级为准，且必须在 `CANON_CONFLICTS.md` 中**记录冲突条目**，不得由代理自行悄悄裁定。
- 同一事实同时存在 2～4 套说法（原著 txt / 旧版游戏设定 / 原著校订版 / 创作圣经 / 美女资料 / 旧二创）时，一律按本优先级选源，不随机抓取。
- 原著 TXT 是本项目外部参考（不复制进仓库）。能落到仓库的原文级事实，只能来自：任务卡、本 worktree README（P0–P1-031 全部内容历史）与 `src/game/content/` 注册表。
- 已上线且未被正式废止的游戏行为 = 当前代码与存档连续性事实，是"已上线游戏连续性"档（第 4 档）。
- 本阶段新增的规划内容（Act 骨架、未来角色、坐骑目录等）一律标 `[PLANNED]`，不冒充已实现事实。

## 3. 标签规范（任务卡第 119 节）

每份人物/剧情资料必须使用以下标签（或等效明确标记），不允许裸写无来源事实：

| 标签 | 含义 | 使用条件 |
|---|---|---|
| `[CANON]` | 已上线游戏里确认的事实 | README P0–P1-031 记录 + `src/game/content/` 注册表可核实 |
| `[PROJECT-AU]` | 项目对原著的改编 | 已记录于 `au/AU_CHANGES.md`（AU-001~005）或后续新增 AU |
| `[PLANNED]` | 未来规划内容 | 尚未实现，仅出现在 MASTER_OUTLINE / Act 骨架 / 目录 |
| `[UNKNOWN]` | 无法从权威输入核实的事实 | 原著具体细节无章段来源时一律标注，**不许猜测** |

补充规则：

- `[UNKNOWN]` 不是"随便写"的借口：凡无法从权威输入（任务卡 / README / 注册表 / 任务卡引用的原著章段）核实的内容，要么标 `[UNKNOWN]`，要么根本不写。
- 禁止 `"据原著"` 而不给章段（任务卡第 10 节）。原著事实必须给来源章段。
- `[CANON]` 事实以代码/README 为准；当任务卡与 README 对同一已实现系统表述不一致时，以当前代码实际行为为准（已上线连续性 > 旧设计文档）。

## 4. 本阶段裁定（TM-P2-007 阶段范围）

- 本阶段是 **Canon 资料层建立 + 系统基础** 阶段，不是新剧情扩张阶段。
- 已实现内容（Golden Rabbit 黄金兔子线 / North Gate 北门失联 / Sakura early encounter）作为项目 AU 插入 MASTER_OUTLINE 合理位置并标注。
- 禁止把本阶段规划内容（水雾殿正式主线、莉安雅正式获取、百幻桃林、狐媚儿、司马幽兰、精灵峡谷、天妖夫人、大日岛正式地图、武斗大会、天梦终局）当作"已实现"写入任何资料。
- 本阶段实际新增剧情只允许两个 vertical slice：早期 Mount 获取 + 一个多解现有支线（任务卡第 122 节）。

## 5. 判定快速表

遇到某条待定事实时，按顺序自问：

1. 用户是否已明确裁定过？→ 是则直接采用，记录来源。
2. 是否在 `00_DECISIONS.md` / `AU_CHANGES.md` 已裁定？→ 采用。
3. 是否能在任务卡引用的原著章段核实？→ 采用并标来源章段。
4. 是否能在 README / `src/game/content/` 核实为已上线行为？→ 标 `[CANON]` 采用。
5. 是否属于未来规划且方向已由任务卡第 12 节主结构给出？→ 标 `[PLANNED]`。
6. 其余 → 标 `[UNKNOWN]`，不写、不猜。

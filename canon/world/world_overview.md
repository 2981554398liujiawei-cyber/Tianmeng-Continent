# 天梦大陆世界观总览（World Overview）

> 本文件汇总《天梦大陆》世界观。已实现内容标 `[CANON]`（来源：README P0–P1-031 + `src/game/content/`），未来规划标 `[PLANNED]`（来源：任务卡第 12 节主结构），无法核实标 `[UNKNOWN]`。

## 1. 世界基调

- `[CANON]` 单人、浏览器运行、文字叙事驱动的 **D20 奇幻 CRPG**：场景节点式探索、回合制战斗、角色成长与装备、NPC 对话与关系变化、分支剧情与世界状态变化（README 首段）。
- `[CANON]` 技术形态：React 19 + TypeScript + Vite + Zustand + Tailwind v4 + localStorage 存档 + Cloudflare Worker/D1 云存档（README 技术栈 / Cloud Save 段）。
- `[PROJECT-AU]` 原著为 MMO，项目改编为单机 CRPG（AU-005）。MMO 要素（玩家经济模拟、排行榜竞争、实时在线、帮派后台、百人战场）一律不做；保留世界观、任务、幸运、装备、坐骑、隐藏事件、美女 NPC、职业与原著关键故事。

## 2. 文明与秩序

- `[CANON]` **天龙王朝**：皇城为天龙城（`tianlong_city`「天龙王朝的皇城。高大的城墙、宽阔的街道与成片建筑构成这座繁华城市。」）；城内有武馆（`tianlong_martial_hall`）与骑士编制（骑士队长马科）。
- `[CANON]` **青石村**：群山环抱的小村（`qingshi_village`），村民由村长、铁匠、药师构成；新手村。
- `[CANON]` **大日岛樱花神宫**：樱花优子的出身（`companions.ts` summary「来自大日岛樱花神宫的女神」）。神宫本体在项目里尚属远景（见 Act X `[PLANNED]`）。
- `[PLANNED]` 其它势力（水雾殿、百幻桃林、秦皇古墓相关、精灵峡谷、百兽、阴风殿、天梦仙山等）见 `factions.md` 与 `geography.md`，均为未来 Act 规划。

## 3. 主角与起点

- `[CANON]` 主角自由创建：姓名（1–16 字符）、性别（男/女）、职业（战士/骑士/游侠/法师）、五属性分配（力量/体质/敏捷/冥想/幸运，初始各 8，可分配 14 点，总和 54）。
- `[CANON]` 默认起点：青石村；初始金币 50；基础背包铁剑 ×1、治疗药水 ×2。
- `[CANON]` 已实现的成长里程碑：完成《草原狼影》达成 Lv.2（`[CANON]`，TM-P1-011，唯一升级来源；`LEVEL_2_MAX_HP_GAIN=2`、`LEVEL_2_MAX_MP_GAIN=1`）。
- `[PLANNED]` 未来升级/经验系统（当前只有 adventureXpReward 数据与 Lv.2 里程碑，无通用经验系统）。

## 4. 超自然与力量体系

- `[CANON]` **D20 检定体系**：五档 DC（`CHECK_DC`）、天然 20 大成功 / 天然 1 大失败；属性修正 `floor((score-10)/2)`、熟练加值五档。
- `[CANON]` **战斗规则 V3**：命中 `(攻击者敏捷 + D20)/2 >= 防守者敏捷`；天然 1 大失败 0 伤、天然 20 暴击 200%；护甲减伤 `max(1, ceil(raw × roll/(armor+roll)))`；先手 `D20 + AGI`。
- `[CANON]` **幸运（Luck）**：正式影响怪物掉落、宝箱、命运补救、机缘社交（`src/game/rules/luck.ts`）。
- `[CANON]` **魔化异象**：青石村一带野兽「魔化」（魔化兔/鼠/狼、嘟嘟兔），根源未明（黄金兔子线伏笔 `[PLANNED]`）。
- `[CANON]` **亡灵异象**：黑石塔被亡灵占据（骷髅士兵/队长/僵尸/黑法师/骷髅战士/骷髅女妖），夔峒项链遗失于此（Phase 1 已收口）。
- `[CANON]` **神域裂隙**：樱花女神神域崩落，`sakura_domain_fragment`（樱华神域·破碎边界）连接残灾之影。
- `[PLANNED]` 灵浴/温泉、神契、契约魔法等体系随对应 Act 展开。

- `[PLANNED]` 原著职业扩展 `[UNKNOWN]`：原著职业体系细节待回查（`novel_chapter_index.md` 登记「职业」为待提取要素）。
